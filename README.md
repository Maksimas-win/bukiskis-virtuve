# Bukiškių parapijos virtuvės atnaujinimas

Bukiškių Kristaus Gimimo parapijos virtuvės atnaujinimo ir paramos projektas.

## Projekto biudžetas

- Bendra projekto vertė: **6 200 €**
- Jau surinkta: **1 500 €**
- Liko surinkti: **4 700 €**
- Dabartinė pažanga: **24,2 %**

## Projekto tikslas

Atnaujinti esamą parapijos virtuvę ir sukurti šviesią, praktišką, tvarkingą bei ilgaamžę erdvę parapijos bendruomenei.

## Etapai

1. Patalpos ištuštinimas, sienų paruošimas, glaistymas ir dažymas.
2. Naujų virtuvės baldų, stalviršio ir darbo zonos įrengimas.

Svarbu: **1 500 € nėra atskiro pirmojo etapo kaina.** Tai jau surinkta viso projekto suma, leidžianti pradėti pirmuosius darbus.

## Svetainė

- Statinė HTML / CSS / JavaScript svetainė
- LT / RU kalbų perjungimas be puslapio perkrovimo
- Pasirinkta kalba išsaugoma `localStorage`
- Responsive dizainas telefonams, planšetėms ir kompiuteriams
- GitHub Pages deployment per `.github/workflows/pages.yml`
